# 进制转换器

免费在线进制转换工具站：二进制、八进制、十进制、十六进制任意互转，配套原创教程与速查表。

## 功能特性

- **综合转换器**：四栏（2/8/10/16 进制）输入实时联动，一页完成所有换算
- **指定进制互转**：首页 tab 标签切换、内页下拉框切换，支持任意进制组合
- **任意进制换算器**：百科页支持 2-36 进制常用基数互转
- **大数不丢精度**：按位做大数运算，超长二进制串/地址转换零误差
- **输入容错**：自动忽略 `0x` / `0b` / `0o` 前缀及空格、下划线，十六进制不区分大小写
- **纯前端本地运行**：不经过服务器、不收集任何输入数据

## 页面结构

| 页面 | 说明 |
|---|---|
| `index.html` | 首页：综合转换器 + tab 版指定互转 + 换算教程 + FAQ |
| `binary.html` | 二进制转换器（预置二进制 → 十进制） |
| `octal.html` | 八进制转换器（含 Linux 权限 755 实例） |
| `decimal.html` | 十进制转换器（除基取余完整演算） |
| `hex.html` | 十六进制转换器（颜色码 / 内存地址实例） |
| `guide.html` | 进制转换百科（位权公式、补码、小数转换） |

## 技术说明

- 纯静态 HTML / CSS / 原生 JavaScript，无任何依赖、无需构建
- `js/converter.js`：全站共用换算逻辑（大数逐位运算）
- `js/baidu-analytics.js`：全站共用百度统计代码
- `assets/logo.svg`：站点 Logo（兼 favicon）
- `robots.txt` / `sitemap.xml`：搜索引擎收录配置
- 全部换算在浏览器本地完成，可直接部署到 Cloudflare Pages / GitHub Pages 等任意静态托管
