二进制是什么：只用 0 和 1 的计数方式

两个符号撑起整个数字世界

二进制（Binary）是基数为 2 的进位计数制，任何数都由 0 和 1 两个符号排列而成，运算规则是「满二进一」。它的每一个数位被称为一个比特（bit），8 个比特组成一个字节（Byte），这是我们衡量文件大小、内存容量的最小单位链。你在硬盘上看到的 KB、MB、GB，本质上都是在数有多少个二进制位。

二进制数换算成十进制使用「位权展开」：从右往左，每一位的位权分别是 2 的 0 次方、2 的 1 次方、2 的 2 次方……把每个 1 所在位置的位权加起来即可。例如二进制 1101011：

1101011 = 1×64 + 1×32 + 0×16 + 1×8 + 0×4 + 1×2 + 1×1

= 64 + 32 + 8 + 2 + 1 = 107（十进制）

反方向（十进制转二进制）用「除 2 取余、余数倒排」：把数不断除以 2 记录余数，直到商为 0，再把余数从下往上读出。比如 45 ÷ 2 依次余 1、0、1、1、0、1，倒排得 101101。

读二进制的捷径：4 位一组看十六进制

二进制位数一多，人眼很难快速判断大小，这时借用十六进制会轻松很多。由于 2 的 4 次方等于 16，每 4 个二进制位恰好对应 1 个十六进制字符。从右往左每 4 位分组、高位补零，逐组替换：

1101011 → 分组 0110 | 1011 → 查表 6、B

二进制 1101011 = 十六进制 6B = 十进制 107

这也是为什么调试器、十六进制编辑器里看到的内存数据总是以 0x 开头——一位十六进制就是 4 个比特的「压缩写法」，8 位二进制只需要两个字符就能表示。

二进制在真实工作里的四个高频场景

位运算与标志位

权限系统常用一个整数的不同二进制位表示多项开关：读 = 4（100）、写 = 2（010）、执行 = 1（001），三者按位或得到 7（111）即全部开启。判断某权限是否开启用按位与，开关某一位用按位异或——都要求你能瞬间在二进制和十进制之间来回换算。

寄存器与硬件配置

单片机、网卡、显卡的数据手册里，寄存器每个比特都有名字和含义。配置时经常要写出形如 0b10100110 的二进制字面量，或者把手册里的位说明拼成完整字节，转换器能帮你省掉大量手算。

IP 地址与子网掩码

IPv4 地址的每一段都是 8 位二进制，子网掩码 /24 意味着前 24 位是网络位。判断两个 IP 是否同网段、计算可用主机数，都要把十进制点分写法还原成二进制来对比。

考试与刷题验算

计算机等级考试、考研 408、数字电路课程都把进制换算列为必考基础题。手算完用工具核一遍结果，两秒钟定位步骤错误，比同学之间互相对答案高效得多。

二进制转换常见问题

二进制数 1011 换成十进制是多少？

按位权展开：1011 = 1×8 + 0×4 + 1×2 + 1×1 = 11。快速口诀是从左往右「遇 1 加权」：8 加 0 加 2 加 1。也可以用本页转换器直接验证。

二进制怎么快速转十六进制？

从右往左每 4 位分成一组，最高位不足补 0，然后每组查上表替换成一个 0-F 字符。例如 1101011 分组为 0110 / 1011，即十六进制 6B。反向转换同样简单：每个十六进制字符展开成 4 位二进制即可。

为什么二进制在计算机里如此重要？

计算机的晶体管只有导通和截止两种稳定状态，天然对应 0 和 1。二进制电路只需区分高低电平，抗干扰强、成本低，而且与、或、非逻辑运算可以直接用门电路搭出来，加法器等运算部件因此设计简单，所以二进制成了整个数字系统的底层语言。

负数在二进制里怎么表示？

计算机用补码表示负数：正数的补码是它本身，负数的补码 = 对应正数按位取反后加 1。例如 8 位二进制里，+5 是 00000101，-5 则是 11111011。最高位是符号位，这也是为什么 8 位有符号数的范围是 -128 到 +127。

二进制小数怎么转换？

整数部分用除 2 取余，小数部分则用乘 2 取整：每次乘以 2，取出整数部分作为二进制位，再用剩余小数继续乘。例如 0.625 → 0.101。注意很多十进制小数（如 0.1）在二进制下是无限循环的，这正是浮点数运算会出现 0.1 + 0.2 ≠ 0.3 的原因。
